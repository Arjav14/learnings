The Kernel

Think of the kernel as the control center of your computer — the core that manages everything happening under the hood. When your programs need to use your keyboard, mouse, USB stick, or display, they don't talk to the hardware directly. They go through the kernel, which handles those requests efficiently.

It also decides which program gets access to the processor at what time, manages the hard disk, and responds to interrupts . No matter what you're doing — from typing a document to running a robot — the kernel is quietly running the show.

What's Linux?

Linux is a free and open-source kernel,it eventually became the heart of many operating systems — we call them Linux distributions or distros. It was adopted to create a completely free alternative to Unix.

Today, Linux powers everything from servers and supercomputers to Android phones and robots. A full Linux-based system doesn't just include the kernel — it also has system tools, user libraries, and utilities that make it usable for both humans and programs.

Linux vs macOS vs Windows (from a robotics perspective)

In robotics, Linux is the king. Why? Because it's flexible, lightweight, secure, and most importantly, ROS (Robot Operating System) is built for it.

Windows does get used, especially in industry or with simulation tools, and macOS lags behind mostly because it's locked into Apple's ecosystem and is quite expensive. Linux also has a strong command-line interface, open-source transparency, and a huge global community — all of which make it ideal for research, development, and deployment in robotics.

The Linux Distro Families – Who's Who in the Penguin World

There are a few major Linux families you should know:

Red Hat Family (e.g., Fedora, CentOS, RHEL)

Built for business. Think of it like enterprise Linux — stable, secure, but not free in some cases. Uses the RPM package format with tools like dnf.

SUSE Family (e.g., openSUSE, SLES)

Another enterprise-grade distro, focused on reliability. Uses the zypper package manager.

Debian Family (e.g., Debian, Ubuntu, Linux Mint)

Community-driven, stable, and one of the most popular choices for robotics. Uses the apt package manager.

Why Ubuntu Specifically?

We mostly use Ubuntu in robotics for a few really good reasons:

  • ROS is made for Ubuntu, with official support and packages.
  • Ubuntu LTS (Long Term Support) releases are rock-solid and supported for years.
  • It works perfectly with tools like Gazebo, RViz, MoveIt, OpenCV, and TensorFlow.
  • Has strong community support and loads of tutorials.
  • Plays nicely with popular hardware like Raspberry Pi, Jetson, and Intel NUC.
  • Great for both desktop development and embedded systems.

Shell, Command Line, and Filesystem – Your Toolkit

The Shell is a program that takes your typed commands and runs them. Ubuntu uses Bash by default. You can also try other shells like zsh or fish.

The Command Line Interface (CLI) is how you interact with the shell — it's like talking to your robot or system in plain text. Type in commands, get things done.

Ubuntu's Filesystem is structured like a tree, starting from the root directory /. Key folders include:

  • /home – your personal files
  • /etc – config files
  • /bin, /usr/bin – essential commands
  • /var – log files
  • /tmp – temporary files

Everything — files, folders, even hardware — is treated as a file in Linux.

ROS 2 – The Robot Brain Framework

Finally, ROS 2 (Robot Operating System 2) is the go-to middleware for robotics. It helps us connect different parts of the robot's software, from sensors to controllers, using a modular, plug-and-play system. It supports:

  • Real-time control
  • Multi-robot setups
  • Secure communication
  • Flexible design using DDS for reliable messaging

Whether you're programming a drone, rover, or robotic arm — ROS 2 helps you scale and manage your robot's "brain" with ease.
